Download Latest Version

Visit the GitHub Releases page to find the installer for your operating system.

Security & Signing

Novellis is currently in Early Access, and our binaries are unsigned. This may trigger warnings from your operating system during installation.

macOS (Gatekeeper)

If you see a message saying Novellis "cannot be opened because the developer cannot be verified":

  1. Open your Applications folder.
  2. Right-click (or Control-click) the Novellis app.
  3. Select Open from the menu.
  4. Click Open in the dialog box that appears.

Windows (SmartScreen)

If Windows SmartScreen prevents the app from starting:

  1. Click More info.
  2. Click Run anyway.
tip

Make sure to check the System Requirements section before installing to ensure the best performance for local AI models.
